# How to offer mock exams in RootWright LMS

A mock exam is a practice exam a learner takes when they choose. RootWright LMS Pro draws each one fresh from a pool of questions, and only from the parts of the course that learner has completed. Turn it on in the course builder under **Mock exams**.

::: pro
Mock exams are part of RootWright LMS Pro.
:::

![The Mock exams tab before mock exams are turned on](/images/quizzes/mock-exams-01-off.jpg)

*Course builder → Mock exams. Switch on **Offer mock exams in this course** to show the settings.*

## Set up mock exams

::: steps
1. Open the course in the course builder and click **Mock exams**.
2. Switch on **Offer mock exams in this course**.
3. Under **The questions**, tag each question to **The part of the course this question is about**. Choose a module or a lesson. A question that is **Not in the pool yet: tag it** is never drawn.
4. Set how a mock exam is built. The options are in the table below.
5. Click **Save mock exams**. A "Mock exams saved." message confirms it.
:::

If the course has no questions yet, the tab says so. Use **Write questions** to open the lesson builder, write them there, then come back and tag them.

## Options

| Option | What it does |
|---|---|
| **Questions in a mock exam** | From 5 to 200, spread evenly over the modules the learner has completed. A learner has a mock exam once that many questions are unlocked for them. |
| **Share of the points needed to pass, in percent** | The pass mark. |
| **Time limit, in minutes** | 0 for none. |
| **Free mock exams for each learner** | Leave empty for no limit. A mock exam that was started counts, whatever becomes of it. |
| **Hours between mock exams** | 0 for none. Counted from when the last one was handed in. |
| **What the learner sees afterwards** | What the learner is shown once the exam is marked. |

## The question pool

- The summary line counts the questions **in the pool**, those **not tagged yet**, and those **retired**.
- **Retire** takes a question out of the pool without deleting it. **Bring back** returns it.
- Questions tagged to a part of the course with no lesson to complete are never asked. The tab warns you about them.
- **Written answer: you mark it.** Written-answer questions need marking on every mock exam that draws them.
- If the pool can never fill a mock exam, the tab warns you. Tag more questions, or make the mock exam shorter.
