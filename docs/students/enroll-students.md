# How to enroll students in RootWright LMS

To enroll a student, go to **RootWright LMS → Students**, click **Add students**, and choose either an existing WordPress user or a new account. Pick the courses, then click the button to add the student.

## Add a student

::: steps
1. Go to **RootWright LMS → Students** and click **Add students**.
2. Under **Add as**, keep **Student** selected.
3. Choose a tab: **Existing WordPress user**, **New account** or **Import CSV**.
4. Fill in the fields for that tab (see below).
5. Under **Enroll in courses**, search for a course and select it. This step is optional.
6. Leave **Send welcome email** on, or switch it off.
7. Click **Create account** (for a new account) or **Add students**.
:::

![The Add people drawer with the Existing WordPress user tab](/images/students/add-people-01-drawer.jpg)

*The Add people drawer. The Student and Instructor switch sets the role.*

## The New account tab

- **Email**, **First name** and **Last name**.
- The username comes from the email address. The student sets a password from the welcome email, so you do not enter one.
- If the email already has an account, that account is used.

![The New account form filled in for a demo student](/images/students/add-people-02-new-account.jpg)

*A new account. Demo data shown here uses example.com addresses.*

## Enroll in a course

Search for a course in **Enroll in courses**. Each selected course shows its price and access. Free courses show "Free · access granted, no order created".

![A demo student selected for Intro to Watercolor Painting](/images/students/add-people-03-enroll.jpg)

## Import several students

Use **Import CSV** to add many students at once. The button is on the Students screen too.

## After enrolling

The Students list shows the new student with the course count, progress, last active date, join date, amount spent and status. Click a student to open their profile. See [Student profile and progress](/students/student-progress).


::: info
Turning off **Send welcome email** means the student gets no message. Tell them how to sign in yourself.
:::
