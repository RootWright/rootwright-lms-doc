# How to create course categories in RootWright LMS

Categories group courses in the catalog. Create them once under **Teaching → Categories & tags**, then pick one for each course in its **Course category** field.

## Create a category

::: steps
1. Go to **RootWright LMS → Teaching**, then open **Categories & tags**.
2. Click **New category**.
3. Enter a **Category name**, for example "Art and Craft".
4. Click **New category** in the dialog. The category appears in the list with its slug, such as `art-and-craft`.
:::

![The Categories list with Art and Craft added](/images/courses/categories-02-added.jpg)

*The list shows each category, its slug and how many courses use it.*

![The Categories screen before any category exists](/images/courses/categories-01.jpg)

*The Categories screen with no categories. Use **New category** to add one.*

## Assign a category to a course

Open the course in the editor, go to **Details**, and choose a value in **Course category**. The field searches existing categories. If it shows "No results found", create the category first.

## Rename a category

Use **Rename** next to a category to change its name.
