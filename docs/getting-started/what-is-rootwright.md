# What is RootWright LMS

RootWright LMS is a learning management system (LMS) that runs inside WordPress. You build courses from lessons and quizzes, enroll students, track their progress and issue certificates, all from the WordPress admin. The Free plugin covers the core course workflow. The Pro plugin adds paid checkout, live meetings, video hosting, AI tools and more.

## What you can do with each plan

| Area | Free | Pro |
|---|---|---|
| Create courses, modules and lessons | Yes | Yes |
| Text, video with caption, quiz and Q&A lessons | Yes | Yes |
| Enroll students and track progress | Yes | Yes |
| Certificates on course completion | Yes | Yes |
| Teacher roles and permissions | Yes | Yes |
| Sell courses with Stripe or PayPal | No | Yes |
| Host videos on Bunny.net, Cloudflare Stream or YouTube | No | Yes |
| Live classes on Zoom or Google Meet | No | Yes |
| FluentCRM and FluentCart connections | No | Yes |
| Drip schedules, gradebook, course Q&A, mock exams | No | Yes |
| AI course generation, AI audit and AI chat | No | Yes |

Pro is an add-on. It needs the Free plugin to be active.

## The admin at a glance

Everything you manage sits under **RootWright LMS** in the WordPress sidebar:

- **Courses** to build and publish courses.
- **Students** to enroll people and see their progress.
- **Orders** and **Subscriptions** for sales (Pro).
- **Course Bundles** to sell several courses together (Pro).
- **Reviews** to moderate course reviews.
- **Course Page Layout** to edit how course pages look.
- **Teacher Permissions** to control what instructors can do.
- **Settings** for every option on the site.

The screen is split into five top tabs: **Dashboard**, **Teaching**, **People**, **Commerce** and **Community**.
